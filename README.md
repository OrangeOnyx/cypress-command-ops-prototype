CYPRESS COMMAND — Interactive App Prototype
===========================================
Design System V1 Final applied to a working copy of the program.

OPEN
----
Open index.html in a browser, or run:
  python3 -m http.server 8765
  then visit http://localhost:8765

FEATURES
--------
- Bone (light) / Near-Black (dark) theme toggle in the top bar
- Home command center with KPIs, interactive site plan, suite drawer
- Site Plan full view — click any suite
- Work Orders table
- Tenants roster (click 109 to open on site plan)
- Logo Terra mark (#A44E12), glass cards, soft shadows
- Soft Sage only as status accent — no green wash on chrome

DEEP LINKS
----------
?theme=dark
?view=site&suite=109
?view=orders&theme=dark
